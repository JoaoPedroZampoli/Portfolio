# Portfólio — João Pedro Zampoli

Site pessoal bilíngue (pt-BR / en) construído com Next.js 15 (App Router), HeroUI e
Tailwind CSS.

O código da aplicação vive em [`portfolio/`](portfolio/) — veja o
[README de lá](portfolio/README.md) para instruções de desenvolvimento,
estrutura de pastas e como adicionar conteúdo.

## Início rápido

```bash
cd portfolio
npm install
npm run dev
```

O site sobe em `http://localhost:3000` e redireciona para `/pt` ou `/en` conforme
o idioma do navegador.
